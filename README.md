# TODO App
================

A simple, pure frontend TODO application using DOM manipulation.

## Hosted Demo
You can view the live demo of the application at: [https://somashekhar161.github.io/TODO-app/](https://somashekhar161.github.io/TODO-app/)

## Description
This TODO app is built using pure frontend technologies, utilizing DOM manipulation to create a dynamic and interactive user interface. The application allows users to create, read, update, and delete (CRUD) TODO items.

****![image](https://github.com/user-attachments/assets/6de44b02-d2ed-45fe-b1f0-cab92121378e)


## Features
* Create new TODO items
* Read and display existing TODO items
* Update existing TODO items
* Delete TODO items
* Pure frontend implementation using DOM manipulation

## Technologies Used
* HTML
* CSS
* JavaScript

## Getting Started
To run the application locally, follow these steps:

1. Clone the repository: `git clone https://github.com/somashekhar161/TODO-app.git`
2. Open the `index.html` file in a web browser to view the application
